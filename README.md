This entry answers make.fun's [One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) bounty with a single letter: **A**, for coffee. No word, no explanation, no punctuation — just the first letter of the alphabet standing for the bolder drink. The program validates that its answer is exactly one character, either "A" (coffee) or "B" (tea), encodes to exactly one UTF-8 byte with no line breaks, and then writes that letter — and nothing else, not even a trailing newline — to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
